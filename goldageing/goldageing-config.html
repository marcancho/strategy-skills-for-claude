⚙️ Configuração GoldAgeing

Configure o administrador, os contactos e a base de dados do sistema de candidaturas.

⚠️ O modo local guarda os dados apenas neste navegador e destina-se a testes. Para produção, configure o Firebase.

👤 Administrador

Mínimo de 8 caracteres.

📞 Contactos

Com indicativo do país, sem "+" nem espaços (ex.: 351910000000).

📘 Como obter a configuração

  1. Aceda à consola do Firebase e crie (ou abra) o projeto GoldAgeing.
  2. Ative a Realtime Database (localização europeia, ex. europe-west1) e copie o URL da base de dados.
  3. Em Definições do projeto → As suas apps, registe uma app Web.
  4. Copie o objeto firebaseConfig e cole-o abaixo em formato JSON.

🔐 Proteger os dados (obrigatório antes de receber candidaturas)

  1. Em Authentication → Sign-in method, ative Email/Password.
  2. Em Authentication → Users, crie o utilizador administrador e copie o seu User UID.
  3. Em Realtime Database → Dados, crie o nó admins com a chave igual ao UID e o valor true.
  4. Em Realtime Database → Regras, cole o conteúdo do ficheiro firebase-database.rules.json e clique em Publicar.
  5. Guarde a configuração abaixo e use Testar Conexão: deve indicar que a base de dados está protegida.

Em modo Firebase, o painel administrativo pede o email e a password do Firebase; a password local deixa de ser usada.

🔥 Configuração Firebase

Campos obrigatórios: apiKey, authDomain, databaseURL, projectId.

Antes de publicar, substitua a linha const EMBEDDED_CONFIG = null; no formulário e no painel pelo texto copiado. Sem isso, os visitantes não recebem a configuração e o formulário funciona em modo local.
