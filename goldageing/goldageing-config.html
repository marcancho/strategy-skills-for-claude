⚙️ Configuração GoldAgeing

Configure o administrador, os contactos e a base de dados do sistema de candidaturas.

⚠️ O modo local guarda os dados apenas neste navegador e destina-se a testes. Para produção, configure o Firebase.

👤 Administrador

Mínimo de 8 caracteres.

📞 Contactos

Com indicativo do país, sem "+" nem espaços (ex.: 351910000000).

📘 Como obter a configuração

  1. Aceda à consola do Firebase e crie (ou abra) o projeto GoldAgeing.
  2. Ative a Realtime Database e copie o URL da base de dados.
  3. Em Definições do projeto → As suas apps, registe uma app Web.
  4. Copie o objeto firebaseConfig e cole-o abaixo em formato JSON.

🔥 Configuração Firebase

Campos obrigatórios: apiKey, authDomain, databaseURL, projectId.
